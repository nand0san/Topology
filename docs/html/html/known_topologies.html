finite_topology.known_topologies.create_alexandrov_topology(space, order_relation, relation_type='function')¶

Create the Alexandrov topology on the given space based on an order relation.

The Alexandrov topology is a topology where arbitrary intersections of open sets are also open. This topology is commonly used in domain theory and order theory.

In the Alexandrov topology, for each element \(x\) in the space, the “upward set” that contains all elements greater than or equal to \(x\) (according to the order relation) forms an open set.

Example

Consider the set \(\{a, b, c\}\) with the following order relation:

  • \(a \leq b\)

  • \(b \leq c\)

The upward sets would be:

  • \(\{a, b, c\}\) (starting from \(a\))

  • \(\{b, c\}\) (starting from \(b\))

  • \(\{c\}\) (starting from \(c\))

In this example, the open sets in the Alexandrov topology are the arbitrary unions of these upward sets, along with the empty set.

Parameters:

  • space (set) – The set over which the topology is defined.

  • order_relation (Callable[[Any, Any], bool] or Dict[Any, Set[Any]]) –

    • If relation_type is ‘function’: A function that takes two elements \(x, y\) and returns True if \(x \leq y\).

    • If relation_type is ‘dict’: A dictionary where order_relation[x] is a set of elements greater than or equal to x.

  • relation_type (str) – Specifies the type of order_relation (‘function’ or ‘dict’).

Returns:

An instance of the Topology class representing the Alexandrov topology.

Return type:

Topology

finite_topology.known_topologies.create_discrete_topology(space)¶

Create a discrete topology on the given space.

A discrete topology on a set \(X\) is the topology in which every subset of \(X\) is open. This means that the topology \(\tau\) is equal to the power set of \(X\).

\[\tau = \mathcal{P}(X)\]

Example

A function from any space with a discrete topology to any other topology is continuous.

Parameters:

space (set) – The set over which the discrete topology is defined.

Returns:

An instance of the Topology class representing the discrete topology.

Return type:

Topology

finite_topology.known_topologies.create_divisibility_topology(space)¶

Create a divisibility topology on the given space.

A divisibility topology on a set of integers is defined so that the basic open sets are all multiples of each element in the space. Specifically, for each element \(n\) in the space, the set of all multiples of \(n\) within the space is considered an open set.

Example

Consider the set \(\{1, 2, 3\}\). The divisibility topology would include: - \(\emptyset\) - \(\{1, 2, 3\}\) (all multiples of 1) - \(\{2\}\) (multiples of 2) - \(\{3\}\) (multiples of 3) - Any union of these sets, such as \(\{1, 2\}\), \(\{1, 3\}\), etc.

Parameters:

space (set) – The set over which the divisibility topology is defined. Expected to contain integers.

Returns:

An instance of the Topology class representing the divisibility topology.

Return type:

Topology

finite_topology.known_topologies.create_excluded_point_topology(space, excluded_point)¶

Create an excluded point topology on the given space.

An excluded point topology on a set \(X\) is defined so that the only open sets are those that do not contain a particular point \(e \in X\), along with the entire set and the empty set.

Parameters:

  • space (set) – The set over which the excluded point topology is defined.

  • excluded_point (Any) – The point that is excluded from all non-empty open sets.

Returns:

An instance of the Topology class representing the excluded point topology.

Return type:

Topology

Raises:

ValueError – If the excluded point is not an element of the space.

finite_topology.known_topologies.create_indiscrete_topology(space)¶

Create the indiscrete (trivial) topology on the given space.

An indiscrete topology (also known as the trivial topology) on a set \(X\) contains only the empty set and the entire set.

\[\tau = \{ \emptyset, X \}\]

Example

A function to any space with an indiscrete topology is always continuous.

Parameters:

space (set) – The set over which the indiscrete topology is defined.

Returns:

An instance of the Topology class representing the indiscrete topology.

Return type:

Topology

finite_topology.known_topologies.create_particular_point_topology(space, particular_point)¶

Create a particular point topology on the given space.

A particular point topology on a set \(X\) is defined so that every non-empty open set must include a distinguished point \(p \in X\).

Example

In a particular point topology, the only continuous functions are those that are constant or map the distinguished point to any open set.

Parameters:

  • space (set) – The set over which the particular point topology is defined.

  • particular_point (Any) – The distinguished point that must be included in all non-empty open sets.

Returns:

An instance of the Topology class representing the particular point topology.

Return type:

Topology

Raises:

ValueError – If the particular point is not an element of the space.

finite_topology.known_topologies.create_upward_closed_topology(space, order_relation)¶

Create a topology where open sets are upward-closed sets in a partial order.

An upward-closed topology (or upper sets) contains, along with each of its elements, all greater or equal elements according to the given order relation.

This type of topology is useful in order theory and domain theory, particularly in theoretical computer science and lattice theory.

Example

Consider the set \(\{1, 2, 3\}\) with the usual ordering of integers. In this case, the upward-closed sets would be: - \(\emptyset\) - \(\{1, 2, 3\}\) (starting from 1) - \(\{2, 3\}\) (starting from 2) - \(\{3\}\) (starting from 3)

Parameters:

  • space (set) – The set over which the topology is defined.

  • order_relation (Callable[[Any, Any], bool]) – A function that takes two elements \(x, y\) and returns True if \(x \leq y\).

Returns:

An instance of the Topology class representing the upward-closed topology.

Return type:

Topology
